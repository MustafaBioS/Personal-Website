# Personal Desktop App
This is a personal desktop app made for me built using a Tauri wrapper for the web version, This version is completely offline to fit the "No Intenet" theme for HackCLub Alchemize.
It features a home portfolio page with featured projects, an about me, and a landing section, it also has blog posts and blog posting functionality for me!

# How To Use?
Download the .exe installer file in the git release to download the application.

# How To Use Locally
git clone https://github.com/MustafaBioS/Personal-Website.git<br>
cd clent<br>
npm run build<br>
cd ..<br>
npm run tauri build<br>
