# What Is The Project?
## Personal Desktop App
This is a personal desktop app made for me built using a Tauri wrapper for the web version, This version is completely offline to fit the "No Intenet" theme for HackCLub Alchemize.
It features a home portfolio page with featured projects, an about me, and a landing section, it also has blog posts and blog posting functionality for me!

# Why Did I Build It?
I built for a little cool portfolio for me and also blog posting which is super cool!

# How To Test
Download the application from the git release and open it and start navigating from the navbar to test the application!

# How To Download?
Download the .exe installer file in the git release to download the application.

# How To Use Locally
git clone https://github.com/MustafaBioS/Personal-Website.git<br>
cd clent<br>
npm run build<br>
cd ..<br>
npm run tauri build<br>

# Inspiration
Wanted to write my thoughts and blogs somewhere online that belonged to me so i thought why not make a personal website with blog posting!

# Theme
This project runs without any required internet connection hence why it fits the "No Internet" theme.
